# Programming Projects

A collection of programming projects developed to practice and demonstrate concepts in web development, Python programming, and AI-based applications.

## Projects

### Task 1 – Login & Registration System
A web-based authentication system that allows users to register, log in, and securely access their accounts.

**Technologies:** HTML, CSS, JavaScript, Node.js, Express.js, SQLite

### Task 2 – Study Notes Assistant
A PDF-based study assistant that generates organized study notes and answers questions using Retrieval-Augmented Generation (RAG) and Google Gemini.

**Technologies:** Python, Streamlit, PyPDF, Scikit-learn, Google Gemini API

### Task 3 – Website Summarizer
A web application that extracts content from websites and generates concise summaries of their information.

**Technologies:** Python, Flask, BeautifulSoup, HTML, CSS
